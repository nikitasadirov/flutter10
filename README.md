# TaskFlow

Локальное Flutter-приложение для управления проектами и задачами. Данные хранятся офлайн в SQLite через Drift.

## Запуск

```sh
flutter pub get
flutter run
```

## Что реализовано

- Пользователи, проекты, участники и роли.
- Задачи, статусы, приоритеты, дедлайны, поиск, фильтры, сортировка и пагинация.
- История изменений, отмена статуса, комментарии и пути к вложенным файлам.
- Корзина задач с восстановлением и окончательным удалением.
- SQL-статистика, тестовый набор на 1 000 пользователей, 100 проектов и 10 000 задач, сравнение запросов с индексом и без него.
- Drift-схема с внешними ключами, индексами, уникальностью email и миграцией добавления `priority`.

## Тесты

```sh
flutter test
```

Тесты проверяют основные сценарии, ограничения связей, атомарность, историю, корзину, статистику, миграцию и тестовую нагрузку.
